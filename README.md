# Análisis de ventas

## Objetivo
Analizar el total de ventas por sucursal y por día para responder: Que proceso se debería mejorar?.

## Datos
Use como base de datos un excel que esta guardado en este repositorio como "VentasSimuladas.xlsx", son datos simulados.

## Herramientas
Python, pandas, SQLite3 y matplotlib.

## Cómo ver el proyecto
Abre `Analisis_ventas.ipynb` en este repositorio. GitHub muestra la notebook en el navegador.

## Hallazgos principales
- Todas las sucursales vende en promedio la misma cantidad a la semana.
- Hubo dos días a la semana en donde bajaron las ventas en general.

## Limitaciones
Son datos simulados.
